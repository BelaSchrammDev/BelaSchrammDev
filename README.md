### Womit ich meine Tage verbringe

Migration einer gewachsenen Access-/VBA-ERP-Lösung in eine verteilte .NET-Architektur
mit EF Core und MariaDB, dazu Sync-Dienst und eine App für die Fahrer. Viel
Reverse Engineering, viel Fehlersuche über Systemgrenzen hinweg, gelegentlich
byte-genau.

Dieser Code ist Firmeneigentum und liegt nicht hier. Was ihr hier findet, sind eigene
Projekte und Sachen aus der Ausbildung.
